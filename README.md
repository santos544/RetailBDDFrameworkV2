# RetailBDDFrameworkV2

Playwright + TypeScript + Cucumber BDD automation framework designed for web and mobile browser testing using iPhone Safari and Android Chrome emulation.

## Overview

This framework demonstrates modern UI test automation practices using:

- Playwright
- TypeScript
- Cucumber BDD
- Page Object Model (POM)
- Hooks
- Parallel execution
- Cross-browser support
- HTML reporting
- Screenshot capture
- End-to-end purchase flows

## Supported Browsers / Devices

- Chrome Desktop
- Firefox Desktop
- Safari Desktop
- iPhone Safari
- Android Chrome
